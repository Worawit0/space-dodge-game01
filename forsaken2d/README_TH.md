# The Forsaken Depths — 2D Dark Survival RPG

เวอร์ชันนี้สร้างใหม่ให้เป็นเกม 2D มุมมองบนลงล่าง โดยยึด “ความรู้สึก” ของ dark survival RPG แบบคลาสสิก แต่ใช้โลก ตัวละคร ศัตรู ภาพ และเนื้อเรื่องต้นฉบับของ The Forsaken Depths

## Godot
แนะนำ Godot 4.7.2 Stable

## วิธีเปิด
1. แตก ZIP
2. เปิด Godot 4.7.2
3. กด Import
4. เลือก `project.godot`
5. รอ import SVG เสร็จ
6. กด F5

## ปุ่ม
- WASD — เดิน
- Shift — วิ่ง
- E — โต้ตอบ
- I — Inventory
- T — จุด/ดับคบเพลิง
- F9 — โหลดเซฟล่าสุด
- Esc — ปิดเมนู

## ระบบที่มี
- Title / New Game / Continue
- Exploration 2D แบบ top-down
- ระบบแสงคบเพลิงและความมืด
- BODY / MIND / HUNGER / TORCH
- Bleeding / Infection / Fracture
- Inventory เต็มจอ
- Item / Weapon / Armor / Books / Key Items
- NPC dialogue + choices
- Maren เข้าร่วม Party ได้
- Ritual circle: Pray / Offer coins / Offer blood
- Limited save ด้วย Wax Seal ที่ Deep Shrine
- Turn-based battle แยกหน้าจอ
- เลือกโจมตี Head / Torso / Left Arm / Right Arm / Legs
- แขนถูกทำลายแล้วดาเมจศัตรูลด
- ขาถูกทำลายแล้วหนีง่ายขึ้น
- Guard / Skills / Items / Run
- ศัตรูทั่วไป + Cultist + Boss
- 3 Ending ตามการตัดสินใจและค่า Mind

## เส้นทางหลัก
Old Prison → Abandoned Infirmary → Temple District → Heart of the Bell

## หมายเหตุด้านภาพ
ภาพ SVG ในโปรเจกต์นี้เป็นงานต้นฉบับสำหรับโปรเจกต์นี้ ไม่ได้คัดลอก sprite, portrait, UI หรือศัตรูจาก Fear & Hunger โดยตรง

## สิ่งที่เหมาะจะเพิ่มภายหลัง
- sprite sheet เดิน 4 ทิศแบบวาดมือ
- ภาพฉาก hand-painted รายห้อง
- portrait บทสนทนา
- SFX/ambient/music
- animation ศัตรูและ blood effect
