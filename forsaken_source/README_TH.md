# The Forsaken Depths

โปรเจกต์ Godot 4.7 แนว 2.5D Dark Survival Horror RPG แบบ vertical slice เล่นได้ตั้งแต่เริ่มจนจบ

## วิธีเปิด
1. แตก ZIP
2. เปิด Godot 4.7.x
3. Import `project.godot`
4. รอ Godot import ไฟล์ .glb ให้เสร็จ
5. กด F5 เพื่อเล่น

## ปุ่ม
- WASD: เดิน
- Shift: วิ่ง
- E: โต้ตอบ
- I: Inventory
- T: เปิด/ปิดคบเพลิง
- Esc: ปิดหน้าต่าง

## ระบบ
HP / Hunger / Sanity / Torch, Bleeding / Infection / Fracture, Inventory, Limited Save, 2.5D exploration, Turn-based body-part combat, Puzzle, NPC choice, Boss battle และ 2 endings.
